# Получение готового CVMatcher.exe через GitHub Actions

Python на вашем Windows-компьютере не нужен.

1. Создайте новый пустой репозиторий на GitHub.
2. Загрузите в корень репозитория всё содержимое этой папки, включая скрытую папку `.github`.
3. Откройте вкладку **Actions** в репозитории.
4. Выберите workflow **Build CVMatcher for Windows**.
5. Нажмите **Run workflow** → **Run workflow**.
6. Дождитесь зелёной галочки у сборки.
7. Откройте завершённую сборку. Внизу страницы, в разделе **Artifacts**, скачайте **CVMatcher-Windows**.
8. Распакуйте скачанный ZIP. Внутри будет `CVMatcher.exe`.

Workflow также запускается автоматически при push в ветку `main` или `master`.

## Если Windows показывает предупреждение

Собранный EXE не подписан коммерческим code-signing сертификатом, поэтому Windows SmartScreen может показать предупреждение для нового/неизвестного приложения. Это не ошибка сборки. Для корпоративного распространения рекомендуется подписывать EXE сертификатом организации.
