# CV Matcher — Windows desktop MVP

Desktop-приложение для сопоставления вакансии с несколькими CV. Поддерживает Drag & Drop резюме, PDF/DOCX/TXT/MD, подробное объяснение по каждому требованию, рейтинг и экспорт в Excel.

## Запуск на Windows
1. Установите Python 3.11+ с python.org (галочка **Add Python to PATH**).
2. Запустите `run_dev.bat`.
3. Откройте **Настройки**, вставьте OpenAI API key и выберите модель.
4. Вставьте/загрузите вакансию.
5. Перетащите несколько CV мышью в область **Резюме**.
6. Нажмите **ПРОАНАЛИЗИРОВАТЬ**.

## Сборка EXE
Запустите `build.bat`. Готовый файл появится в `dist\CVMatcher.exe`.

## Форматы
- Vacancy: PDF, DOCX, TXT, MD
- CV: PDF, DOCX, TXT, MD
- Output: XLSX

PDF-сканы без текстового слоя пока не поддерживаются (OCR намеренно не включён в MVP).

## Безопасность
API key сохраняется через системный credential backend (`keyring`), а не в исходниках. Резюме отправляются выбранной LLM API для анализа, поэтому перед использованием с реальными персональными данными проверьте требования вашей организации к обработке данных.

## Scoring
Модель определяет требования и их веса. Статусы: MATCH=100%, PARTIAL_MATCH=50%, NO_MATCH=0%, NOT_FOUND=0%. Итоговый процент рассчитывается локальным кодом. NOT_FOUND отдельно означает отсутствие достаточных данных, а не доказанное несоответствие.

Инструмент предназначен для поддержки проверки профессионального соответствия, а не для автоматического принятия решения о найме.
